# RPA 实验记录模板

> 任何影响去重、布局解析、消息识别、发送逻辑的修改，都建议先记录实验假设和预期，再执行验证。

---

## 快速开始

每次实验复制以下模板，填写后保存到本文件末尾。

```markdown
## YYYY-MM-DD - [实验名称]

### 背景
[为什么做这个实验？当前遇到什么问题？]

### 假设
[你预期什么改动会带来什么效果？]

### 改动内容
- 文件: `src/xxx.py`
- 具体修改: [一句话描述]

### 验证方法
- [ ] 跑 `python3 scripts/doc_lint.py && python3 scripts/doc_review.py`
- [ ] 跑 `python3 tests/test_integration.py`
- [ ] 跑 `python3 -m pytest src/tests/ -v`
- [ ] 手动截图验证 [N] 轮
- [ ] 其他: [说明]

### 结果
| 指标 | 改动前 | 改动后 |
|------|--------|--------|
| [如: 回声误识别次数] | x | y |
| [如: 滚动去重准确率] | x | y |

### 结论
- ✅ 假设成立 / ❌ 假设不成立 / ⚠️ 部分成立
- 下一步: [继续优化 / 回滚 / 尝试新方向]
```
