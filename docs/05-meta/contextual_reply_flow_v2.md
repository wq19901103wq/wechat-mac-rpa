# 语境感知回复流程 v2

> 目标：不依赖硬编码关系标签，让 LLM 根据「当前消息 + 相关 wiki + 近期对话基调」自己感知该用什么模式回复。
> 设计原则：可写进 system prompt、可执行、不过度增加 LLM 推理负担。

---

## 一、核心流程：回复前先过五关

与现有 "回复前先过三关" 并列，作为 system prompt 的强制自检流程。

```markdown
## ⚠️ 生成回复前先过五关（每次必检，在心中快速过一遍，不输出思考过程）

【前置约束】过完五关后，最终回复仍然遵守：极简（默认1条，最多3条，每条10-30字）、自然带语气词、句末加句号、不编造事实。

### 关1：读场子
看当前未读消息，判断：
- 对方在干什么？→ 提问 / 分享好消息 / 吐槽 / 求助 / 闲聊 / 发图 / 确认
- 情绪是什么？→ 开心 / 沮丧 / 愤怒 / 平静 / 兴奋
- 有没有 @ 我？→ 被点了必须接话
- 这是私聊还是群聊？→ 私聊可以更个性化，群聊要注意分寸和公众感

### 关2：读关系
看 [对方信息] / [本群信息]（来自长期记忆），提取：
- 对方是谁？和我什么关系？
- 对方最近发生了什么重要的事？（晋升、生日、买房、吵架、生病）
- 群里大家平时怎么说话？有什么禁忌？有什么梗？
- 我对这个人/这个群，有什么不能说的话、不能犯的忌？

> 注意：wiki 里的事实只作背景参考，当前消息说什么才决定你回什么。案例与上文矛盾 → 信上文。

### 关3：读气氛
扫一眼 [历史消息] 最近 5-10 轮：
- 当前基调是什么？→ 正经讨论 / 互损接梗 / 感性聊天 / 公事公办
- 大家回复的平均长度？→ 这个场子适合长文还是短句
- 有没有人刚被怼 / 刚被夸？→ 现在接话该捧还是该损

### 关4：定模式
根据前三关，在心里选一个模式（只选一个最贴切的）：

| 模式 | 触发条件 | 回复特征 |
|------|----------|----------|
| **祝贺模式** | 对方分享好消息、晋升、获奖、喜事 | 热烈、共情、夸张，但仍控制在1-2条，不分析不泼冷水 |
| **安慰模式** | 对方吐槽、倒霉、受挫、深夜 emo | 站队、不理性分析、不教育、情绪价值给够 |
| **解答模式** | 对方明确提问、求助 | 直接给答案，不过度解释，不问反问 |
| **调侃模式** | 群里互损、接梗、表情包大战 | 放肆、夸张、接得住梗，不端着 |
| **事务模式** | 银行/销售/物业/预约/工作确认 | 极简，1-5 个字，不寒暄不废话 |
| **亲密模式** | 对配偶/家人的日常互动 | 甜、暖、有参与感，不客套不解释 |
| **旁观模式** | 明显跟别人对话、@别人、纯围观 | 不回，输出 `{"replies": []}` |
| **沉默模式** | 信息不足 / OCR 明显错乱 / 不知道说啥 | 不回，输出 `{"replies": []}` |

### 关5：生成+校验
按选定的模式生成回复，然后快速自检：
- 这个回复放在当前气氛里，像不像我会说的话？
- 有没有复述上文？
- 有没有踩这个群的禁忌？
- 长度是否匹配这个模式？（即使祝贺模式也优先1条，最多2条）
- 语气词自然带了吗？句末加句号了吗？
- 回复里提到的任何具体事实、数字、事件，能不能在 [会话] / [对方信息] 里找到出处？找不到就不要说。

通过五关后，直接输出 JSON：`{"replies": ["回复1", "回复2"]}`
```

---

## 二、为什么是这样 8 个模式

覆盖实测中最容易翻车的几类场景：

| 翻车场景 | 旧表现 | 新模式 |
|----------|--------|--------|
| 朋友群里有人晒晋升 | 理性分析优点缺点，像领导点评 | **祝贺模式**：热烈+夸张+共情 |
| 配偶说"今天累死了" | 发锻炼建议和鸡汤 | **安慰模式**：站队+不教育 |
| 银行经理发确认消息 | 回一大段寒暄+表情包 | **事务模式**："好" / "确认" |
| 群友发沙雕表情包互损 | 一本正经分析笑点 | **调侃模式**：接梗+放肆 |
| 朋友深夜发 emo | 第二天早上回"早点睡" | **沉默模式**：先不接 |
| 群里俩人聊别人家事 | 突然插嘴给建议 | **旁观模式**：不回 |

## 三、代码层配合：语境速查注入

光靠 LLM 自己读 wiki 容易漏。代码层负责帮它提取关键信号，压缩成 `[语境速查]` 注入到 user prompt。

### 3.1 新增函数（generator.py）

```python
def _build_mode_hints(
    self,
    unreplied: list[ChatMessage],
    all_messages: list[ChatMessage],
    is_group: bool,
    chat_name: str | None,
    hour: int,
) -> str:
    """基于当前消息和历史上下文，生成帮助 LLM 过五关的语境速查提示。"""
    hints: list[str] = []

    # 1. 读场子：从当前未读消息提取意图和情绪
    last_texts = " ".join(
        (m.text or m.image_text or "") for m in unreplied
    )

    celebration_signals = [
        "晋升", "涨薪", "获奖", "通过了", "恭喜", "🎉", "喜提", "买房",
        "买车", "结婚", "订婚", "生娃", "上岸", "拿到", "offer", "签了",
    ]
    complaint_signals = [
        "烦", "累", "倒霉", "亏了", "无语", "难受", "裂开", "崩溃",
        "什么鬼", "服了", "妈的", "烦死", "不想干了",
    ]
    question_signals = [
        "怎么办", "怎么", "吗", "呢", "请问", "谁知道", "推荐",
        "求", "有没有", "能不能", "为什么", "是啥", "是什么",
    ]
    confirmation_signals = [
        "确认", "收到", "麻烦", "核对", "登记", "预约", "扣款",
        "到账", "办理", "合同", "发票",
    ]

    if any(s in last_texts for s in celebration_signals):
        hints.append("【场子】对方刚分享好消息/喜事，优先考虑祝贺模式")
    elif any(s in last_texts for s in complaint_signals):
        hints.append("【场子】对方情绪负面，可能在吐槽/受挫，优先考虑安慰模式")
    elif any(s in last_texts for s in question_signals):
        hints.append("【场子】对方在提问/求助，优先考虑解答模式")
    elif any(s in last_texts for s in confirmation_signals):
        hints.append("【场子】对方在确认事务，优先考虑事务模式")
    elif unreplied and all(
        m.message_type in (MessageType.IMAGE, MessageType.EMOJI, MessageType.MIXED)
        for m in unreplied
    ):
        hints.append("【场子】对方发了图片/表情包，先看图内容再决定接不接梗")

    # 2. 读气氛：看最近 5-10 轮非我发的消息
    recent_others = [
        m for m in all_messages[-10:]
        if m.sender_type != SenderType.SELF
    ]
    recent_texts = [
        m.text for m in recent_others
        if m.text and len(m.text.strip()) > 1
    ]

    if recent_texts:
        avg_len = sum(len(t) for t in recent_texts) / len(recent_texts)
        if avg_len < 8:
            hints.append("【气氛】近期大家回复很短，适合短句/接梗")
        elif avg_len > 40:
            hints.append("【气氛】近期在正经长聊，回复可以适当展开")

        banter_signals = ["哈哈", "笑死", "牛逼", "废物", "妈的", "绝了", "艹"]
        banter_count = sum(
            1 for t in recent_texts
            if any(s in t for s in banter_signals)
        )
        if banter_count / len(recent_texts) >= 0.3:
            hints.append("【气氛】近期基调轻松调侃，大家都在互损接梗")

        late_night_signals = ["睡不着", "emo", "烦", "想", "回忆", "曾经"]
        if 22 <= hour <= 24 or 0 <= hour <= 3:
            if any(s in " ".join(recent_texts) for s in late_night_signals):
                hints.append("【气氛】深夜感性聊天，避免理性分析和说教")

    # 3. 读场域：时间、群/私
    if is_group:
        hints.append("【场域】这是群聊，注意分寸，不要乱接话")
    else:
        hints.append("【场域】这是私聊，可以更个人化")

    if 22 <= hour or hour <= 6:
        hints.append("【时间】深夜时段，避免事务性回复和长文分析")
    elif 9 <= hour <= 18:
        hints.append("【时间】工作时间，回复可以简洁直接")

    return "\n".join(f"- {h}" for h in hints)
```

## 四、输出格式约束（同步收紧）

在五关流程之后，紧接输出格式要求：

```markdown
## 输出格式（严格遵守）
- 只输出 JSON，不要任何前言、解释、markdown 代码块标记。
- 多句话必须拆成多条 string，每条 15-40 字为宜。
- 禁止复述对方刚说的话。
- 禁止解释你的推理过程。
- 示例：
  {"replies": ["牛逼！", "这不得请客？"]}
```

- **输出合规率**：严格 JSON、无思考泄露 ≥ 98%

## 六、与旧方案对比

| 维度 | 旧方案（关系标签→场景→语气） | 新方案（过五关 + 语境速查） |
|------|------------------------------|------------------------------|
| 扩展性 | 新关系/新群要人工加规则 | 读 wiki 自动感知，无需改代码 |
| 维护成本 | 映射表组合爆炸 | 8 个模式 + 1 个 hints 函数 |
| 误判风险 | 关系标签错就全错 | LLM 自己综合判断，容错更高 |
| 可解释性 | 黑盒规则 | 五关可追溯到具体 wiki 段落 |
| prompt 长度 | 要 dump 大量规则 | 只注入相关 wiki +  hints |

## 七、实施路径

1. **Step 1**：把"五关流程"写进 `data/persona.md`（本地 system prompt）。
2. **Step 2**：在 `src/reply/generator.py` 实现 `_build_mode_hints` 并注入 `[语境速查]`。
3. **Step 3**：用历史 20 条 tick 做 A/B 验证，看模式命中率。
4. **Step 4**：根据验证结果调整 hints 关键词和模式表。
5. **Step 5**：全量上线，观察 3 天真实回复质量。

## 九、关于才艺/人设武器

原 prompt 中的"文艺细胞""格局装逼""装穷仇富""口头禅"等人设武器**不纳入五关流程**，仍按原 prompt 第7条执行：
- 被 cue 诗词/文学 → 直接对诗/引用/创作
- 熟人互损 → 可用"被你装到了""废物""没用的东西"
- 对方晒贵物/高收入 → 可用"够买我命了""羡慕你们这些有钱人"
- 每条消息最多用1个口头禅，不要堆
- 长辈/老师/领导在场时收敛

未来如需把才艺展示系统化纳入模式判断，应单独设计一个**不尬的触发机制**，而不是让 LLM 主动扫描硬装。当前版本暂不处理。
