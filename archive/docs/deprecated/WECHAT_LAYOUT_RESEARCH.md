# 微信Mac版界面布局研究报告

## 截图规格
- **尺寸**: 1760 x 1280 (Retina 屏幕截图)
- **来源**: macOS 微信 3.x 版本

## 界面分区

```
┌─────────────────────────────────────────────────────────────┐
│ [侧边栏] │ [聊天对象名称]                    [搜索] [更多] │  ← 标题栏 (0-50px)
├──────────┼──────────────────────────────────────────────────┤
│          │                                                  │
│ 头像列表 │  消息区域                                        │  ← 消息区 (50-1127px)
│ (60px)   │                                                  │
│          │  [昵称]                                          │
│          │  ┌──────────────┐                                │
│          │  │ 消息内容      │                                │
│          │  └──────────────┘                                │
│          │                                                  │
├──────────┼──────────────────────────────────────────────────┤
│          │ [输入框]                               [发送按钮]│  ← 输入区 (1127-1280px)
└──────────┴──────────────────────────────────────────────────┘
```

## 颜色特征

| 元素 | RGB 颜色 | 识别方法 |
|------|----------|----------|
| 自己消息气泡 | (176, 240, 167) 绿色 | G > R+30 && G > B+30 |
| 对方消息气泡 | (238, 238, 240) 灰色 | RGB相近, 200-245 |
| 背景 | (250, 250, 250) 白色 | RGB > 245 |
| 标题栏背景 | (248, 248, 248) | 接近白色 |
| 输入区背景 | (237, 237, 238) | 浅灰色 |

## 布局规则

### 1. 消息方向判断
```python
if center_x > width * 0.6:
    direction = "自己"  # 右侧 = 自己消息
else:
    direction = "对方"  # 左侧 = 对方消息
```

### 2. 昵称位置规律
- 位置：消息气泡上方 20-40 像素
- 坐标：x < width * 0.35 (偏左)
- 长度：2-15 个字符
- 颜色：深灰色文字

### 3. 消息内容位置
- 昵称下方 10-30 像素
- 气泡内文字

### 4. 时间戳特征
- 格式：`HH:MM`
- 位置：消息之间，水平居中
- 颜色：浅灰色

## 识别算法

### 步骤 1: 提取所有文本及坐标
使用 Vision OCR 获取所有文本元素的坐标

### 步骤 2: 分区过滤
```python
if y < 50:      → 标题栏（聊天对象名称）
if x < 60:      → 侧边栏（忽略）
if y > 1127:    → 输入区（忽略）
```

### 步骤 3: 元素分类
```python
if re.match(r'^\d{2}:\d{2}$', text):
    → 时间戳
elif len(text) <= 15 and x < width*0.35:
    → 昵称（可能）
else:
    → 消息内容
```

### 步骤 4: 昵称-消息关联
```python
for msg in messages:
    # 找上方最近的昵称
    sender = find_nearest_nickname_above(msg)
```

### 步骤 5: 颜色验证（V3 增强）
```python
# 检查消息气泡颜色验证方向
if direction == "自己" and not is_green_bubble(msg.x, msg.y):
    direction = "对方"  # 修正误判
```

## 当前限制

1. **昵称识别准确率**: 约 60-70%
   - 问题：昵称和消息内容长度有重叠
   - 解决：需要结合气泡颜色/形状验证

2. **标题栏识别**: 聊天对象名称有时被识别为消息
   - 原因：标题栏文字和消息区文字样式相似
   - 解决：严格限制 y < 50 区域

3. **多行消息**: 长消息被分成多个 OCR 结果
   - 解决：需要合并同一气泡内的文本
