# 智能家居控制 Skill

## 一句话摘要
打开/关闭/查询智能家居设备、调节温度、控制场景时启用。

## 触发条件

用户提到以下任意场景时触发：
- 打开/关闭设备："打开客厅灯"、"关掉空调"、"把窗帘拉上"
- 查询设备："列出所有设备"、"有哪些智能家居"、"查看卧室灯状态"
- 调节温度："空调设到26度"、"地暖调到28度"
- 场景控制："回家模式"、"睡眠模式"、"离家模式"

## 控制流程

### STEP 1: 识别用户意图

判断用户想要做什么：
- **列表查询** → 调用 `tuya_list_devices()`
- **开关控制** → 调用 `tuya_control_device(device_name, action)`
- **温度调节** → 调用 `tuya_set_temperature(device_name, temperature)`
- **场景控制** → 拆解为多个单设备控制依次执行

### STEP 2: 设备名称匹配

用户可能使用简称或口语化名称：
- "客厅灯" → 匹配 "客厅主灯"
- "空调" → 匹配 "客厅空调" 或 "主卧空调"（如果只有一个空调则直接匹配，有多个时询问确认）
- "主卧灯" → 匹配 "主卧灯带" 或 "主卧吸顶灯"

如果模糊匹配到多个设备，必须向用户确认："您指的是客厅主灯还是客厅灯带？"

### STEP 3: 执行控制

调用对应工具后，根据返回结果回复用户：
- 成功："✅ 客厅主灯已打开"
- 失败：说明原因（设备离线、不支持该操作、API 异常）
- 未找到：列出可用设备让用户选择

## 场景定义

### 回家模式
- 打开客厅主灯
- 打开客厅空调（设为26度）
- 关闭窗帘

### 睡眠模式
- 关闭所有灯
- 关闭窗帘
- 空调设为睡眠温度（27度）

### 离家模式
- 关闭所有灯
- 关闭空调
- 关闭地暖

## 输出规则

- 控制结果必须明确反馈：设备名 + 动作 + 状态
- 温度调节必须反馈目标温度
- 列表查询必须显示设备在线状态（🟢在线 / ⚫离线）
- 场景控制必须逐项反馈每个设备的执行结果

## 硬性规则

- **绝不猜测设备名称**。如果用户说"把灯打开"而没有指定房间，必须询问："您想打开哪个房间的灯？"
- **绝不执行危险操作**。不支持删除设备、重置设备、修改设备配置等操作。
- **温度范围限制**：空调 16-30℃，地暖 18-28℃。超出范围时拒绝执行并提示合理范围。
- **离线设备提醒**：如果设备离线（⚫），告知用户并建议检查设备电源或网络。
- **单条消息最多控制 3 个设备**。超过时建议分批操作。
