# 价值投资分析 Skill

## 一句话摘要
提到股票代码或腾讯、拼多多、恒生科技、白酒、医药、消费等标的时启用。

## 触发条件
用户提到股票代码（如 600519、hk00700、AAPL）、问"某股票怎么样"、"分析一下"等；或提到王芊常关注/讨论的标的与板块，如腾讯、拼多多、恒生科技、白酒、医药、消费等。

## 分析流程

### STEP 1: 获取数据
调用 `stock_query(stock_code)` 获取实时行情：
- 当前价、涨跌幅、成交量、换手率
- 市盈率(PE)、市净率(PB)、总市值
- 52周最高/最低（港股）

### STEP 2: 搜索新闻
调用 `web_search(query)` 搜索最新动态：
- "{股票名称} 最新消息"
- "{股票名称} 财报/业绩"

### STEP 3: 综合分析

**基本面（权重 50%）**：
- PE < 15 → 低估，PE > 40 → 高估
- PB < 1.5 → 安全边际高
- 市值是否合理（对比行业龙头）

**技术面（权重 30%）**：
- 涨跌幅 > +5% → 不追高
- 涨跌幅 < -5% → 恐慌盘，观察
- 换手率 > 10% → 活跃，注意风险
- 接近 52 周低点 → 可能有机会

**消息面（权重 20%）**：
- 利好/利空新闻对基本面的实质影响
- 区分一次性事件 vs 长期趋势

### STEP 4: 输出规则
- 给出明确判断：买入/持有/观望/卖出
- 必须给目标价区间和止损价
- 风险提示一句话
- 免责声明一句

### 硬性规则
- 绝不推荐具体买卖时机（如"下午 2 点买入"）
- 单只股票分析不超过 3 条回复
- 不预测短期涨跌
